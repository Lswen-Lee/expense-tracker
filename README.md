# 記帳系統

用 Python 內建的 tkinter 與 SQLite 寫的桌面記帳程式，不需要安裝任何額外套件。

## 功能

- **記帳**：月曆每格顯示當日支出與收入，點日期查看當日明細並新增、編輯、刪除記錄
- **記憶**
  - 每次變更立即自動保存
  - 記住上次用的分類；輸入備註時提示以前記過的項目，並帶入當時的分類與金額
  - 固定收支（房租、薪水、訂閱費）到期時自動補上記錄
- **統計**：當月各分類佔比的圓餅圖
- **預算**：各支出分類可設定每月預算，用到 80% 與超支時提醒
- **匯出與備份**：匯出 CSV（可用 Excel 開啟）、備份與還原整份資料

## 執行

需要 Python 3.8 以上（在 Windows 10、Python 3.13 上測試）。

```bash
pythonw main.pyw
```

也可以建立一個指向 `pythonw.exe main.pyw` 的捷徑，之後雙擊開啟。

## 資料

所有記錄存在程式資料夾裡的 `記帳資料.db`，第一次開啟時自動建立。
這個檔案與備份檔、匯出檔都已列在 `.gitignore`，不會被上傳。
